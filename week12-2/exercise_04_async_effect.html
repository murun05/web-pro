EXERCISE 04 / ASYNC

Async/await inside an effect

The effect itself stays synchronous; define and invoke the async function inside it.

Ready.
useEffect(() => {
  async function load() {
    try { const response = await fetch(url); setData(await response.json()); }
    catch (error) { setError(error.message); }
  }
  load();
}, []);
